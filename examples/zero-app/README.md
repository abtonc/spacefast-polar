# Polar on Spacefast Zero

A notes app with a free tier (3 notes) and a Pro subscription sold through Polar. Pro also unlocks a metered API, reported to Polar with `events.ingest`.

| Path | What it shows |
| --- | --- |
| `/` | Notes, gated by the `entitlements` query |
| `/billing` | Upgrade, manage billing, sync after checkout, usage |
| `/debug` | Your user id, the stored entitlements row, and recent webhook deliveries, all live |

The adapter lives in `server/polar/`, vendored from this repo's `src/` (Zero server code cannot import npm packages). It is gitignored and regenerated by `npm run vendor`.

## Run it

1. Create a product (and optionally a meter on the `config_reads` event) in your [Polar sandbox](https://sandbox.polar.sh) organization, then put their ids in `shared/plans.ts`. The ids there belong to the maintainers' sandbox.
2. Vendor the adapter and publish:

   ```bash
   npm install
   npm run vendor
   sf publish
   ```

3. Set the secrets and claim the space so it can reach Polar:

   ```bash
   sf env set POLAR_ACCESS_TOKEN --value-from-stdin
   sf env set POLAR_WEBHOOK_SECRET --value-from-stdin
   sf env set POLAR_SERVER sandbox --no-secret
   ```

4. Make the webhook path public and point a Polar webhook (raw format, `customer.state_changed` plus `order.paid`) at `https://<your-space>/api/polar/webhooks`:

   ```bash
   sf share grant --to public --role viewer --path /api/polar/webhooks
   ```

`sf dev` runs the capsule locally, but Polar can only deliver webhooks to a published space.
